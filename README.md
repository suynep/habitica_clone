# Habitica Clone

Habitica is a habit tracking application I used extensively in my halcyon days. It provides a gamified experience with XP, in-game currency etc. but for day-to-day habits.

> Since I quite like the idea of integrating one's life with a gamified system, and since I'm learning flutter at present, this seems like a fruitful endeavour to immerse myself in.


## Local Development

### Rudimentary setup
```bash
git clone https://github.com/suynep/habitica_clone.git
cd habitica_clone/
flutter pub get # sync packages
```

### Running
After running the rudimentary setup, run:
```bash
flutter devices # view available devices and their ids
flutter run -d <target_id> # choose a platform
```
